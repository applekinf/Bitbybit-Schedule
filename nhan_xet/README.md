# Phiếu nhận xét Tin học

Công cụ chạy trên trình duyệt: nhập danh sách lớp, nhận xét từng học sinh, xuất file Word (mỗi trang A4 có 2 phiếu).

- Chỉ gồm 1 file `index.html`, không cần cài đặt hay máy chủ.
- Dữ liệu được lưu trên trình duyệt của từng người dùng, không gửi đi đâu.
- Cần internet khi mở trang (tải thư viện JSZip, SheetJS và font từ CDN).
